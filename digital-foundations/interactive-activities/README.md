# Digital Foundations Interactive Activities

Single-file HTML activities for the Year 7 Digital Foundations modules.

## GitHub Pages entry point

Open `index.html` to launch the activity suite.

## Activities

- `module_0_laptop_rescue.html` - Laptop Basics & Care
- `module_1_browser_sort_sprint.html` - Browser Basics
- `module_2_name_check_extension.html` - Files & OneDrive
- `module_3_m365_match_lab.html` - Microsoft 365 Essentials
- `module_4_inbox_inspector.html` - Email Essentials
- `module_5_shortcut_arena.html` - Keyboard & Device Skills
- `module_6_privacy_shield.html` - Digital Identity & Safety
- `module_7_search_quest.html` - Search & Information Skills
- `module_8_share_smart.html` - Sharing & Output

Each activity is self-contained and can be embedded directly into SharePoint from its GitHub Pages URL.
