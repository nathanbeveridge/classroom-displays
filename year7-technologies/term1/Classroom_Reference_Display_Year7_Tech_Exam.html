Q2 Python on the micro:bit
Core Program Structure
The Paw Print Button Program
# Always start with this
from microbit import *

# Run forever
while True:
if button_a.is_pressed():
display.show(Image.HEART)
else:
display.clear()
✅ Any image name is fine (e.g. Image.HEART, Image.DUCK)
✅ Indentation matters — use 4 spaces inside the while and if
Key Commands
micro:bit Python Quick Reference
CommandWhat it does
from microbit import * Always the first line. Loads all micro:bit features.
while True: Runs forever. The code inside keeps looping until the device is switched off.
button_a.is_pressed() Returns True if Button A is held down right now, False if not.
display.show(Image.X) Lights up a built-in image on the LED grid. Replace X with the image name.
display.clear() Turns off all LEDs — blank screen.
sleep(1000) Waits 1 second (1000 milliseconds) before the next step.

# do this if FALSE

Pseudocode Concepts
Three Building Blocks
Steps happen one after another, in order. Like a recipe.
The program makes a decision. IF something is true → do one thing. ELSE → do something different.
A block of code repeats. WHILE a condition is true, OR forever (while True).
🔑  The paw print program uses repetition (WHILE) + sequence (steps in order).
🔑  The locker alarm uses repetition (FOREVER) + selection (IF/ELSE).

Q5 Q6 Locker Alarm Algorithm
The Scenario
Locker Door Detector
A micro:bit is placed inside a locker. It uses its light sensor to detect if the door is open.
Dark inside → light level ≤ 150 → show ✔ (tick / safe)
Light enters → light level > 150 → show "WARNING" + beep
It checks the light level every second and runs forever.
Q5 Part A — Model Pseudocode
Your Algorithm Should Look Like This
START
FOREVER DO
SENSE light level
SET light = READ light sensor
IF light > 150 THEN
OUTPUT "WARNING"
OUTPUT beep
ELSE
OUTPUT tick symbol
END IF
WAIT 1 second
END FOREVER
STOP
Q5 Checklist — Your Algorithm Must Include All 6:
FOREVER DO ... END FOREVER (shows it runs forever)
SENSE / READ the light sensor value
IF ... THEN ... ELSE ... END IF (decision)
IF light > 150 → OUTPUT "WARNING" + beep
ELSE → OUTPUT tick symbol
WAIT 1 second before next check
Q6 Part B — Sending a Notification
How to describe the modification (no code needed!)
Inside the IF light > 150 block — the alarm section — add a step to send a message wirelessly.
IF light > 150 THEN
OUTPUT "WARNING"
OUTPUT beep
SEND radio message "LOCKER OPENED" to teacher device ← add this!
Key idea: The micro:bit has a built-in radio module. It can send short messages wirelessly to another micro:bit or device. The teacher's device receives and displays the alert.

A simple answer is fine: "When the alarm triggers, add a SEND step to transmit a radio message to the teacher's micro:bit."
