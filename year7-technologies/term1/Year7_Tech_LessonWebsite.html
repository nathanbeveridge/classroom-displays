Algorithms: WHILE Loops & IF Statements
⏱ 5–15 min
Use the "still hungry" and "contact form" analogies. Ask students for their own real-world WHILE loop examples before introducing the algorithm.
What is an Algorithm? A set of step-by-step instructions that tells a computer what to do. All algorithms use 3 building blocks: Sequence (in order), Selection (IF/ELSE), and Iteration (WHILE/REPEAT loops).
🔵 IF Statement

Checks condition ONCE

Checks if something is true, does one action, then continues on — never repeats on its own.

IF new enquiry THEN show SMILEY face ELSE clear screen END IF
Checks once then moves on. Does NOT loop back.
🔴 WHILE Loop

Keeps repeating

Keeps looping as long as the condition is TRUE. When false, it exits and runs the next line.

WHILE Button A pressed DO show SMILEY face END WHILE clear screen
Loops until button released. Then clear screen runs.

Binary Code → LED Grid
⏱ 25–35 min
Draw a 5×5 grid on the whiteboard. Call out binary digits one at a time — have students shout "ON" or "OFF" before you shade the square. Then reveal the heart.
The Rules
1 = LED ON (shade the square)
0 = LED OFF (leave blank)
Total: 25 digits = 5 rows × 5 columns Read left → right, top → bottom

Step-by-Step Method

  1. Write out all 25 binary digits
  2. Split into 5 groups of 5 (one per row)
  3. For each row: shade squares where digit = 1
  4. Leave squares blank where digit = 0
Heart Example: 0101011111111110111000100

Q1 Explain the Algorithm — up to 75 words

Explain in 2–3 sentences what this algorithm does. Include what happens while the button is held AND after it is released.

WHILE button A is pressed DO show image HAPPY END WHILE clear screen
Model Answer (~65 words)The program runs continuously in a forever loop. While Button A is held down (simulating a new website enquiry arriving), the micro:bit displays a smiley face on its LED screen to alert staff. Once Button A is released, the WHILE loop exits and the clear screen command runs immediately, turning off all LEDs so the display goes blank and the device waits for the next enquiry.
