🎮 Task – Core Gameplay Loop Analysis

Play the prototype above for a few minutes. Your job is to analyse the game design and think about how it could be improved for a specific stakeholder.

Controls

  • Use the mouse or touchpad to thrust the spaceship.
  • Move the cursor to control direction.
  • Avoid obstacles and survive as long as possible.

Part 1 – Identify the Core Gameplay Loop

What does the player do over and over again?

Example structure:
  • Move spaceship
  • Avoid obstacles
  • Collect items
  • Score increases
  • Game speeds up
  • Repeat
Write the loop using arrows: Move → Avoid → Collect → Score → Repeat

Part 2 – Mechanics, Dynamics, Aesthetics

Think about the MDA framework.
  • Mechanics – rules of the game
  • Dynamics – what happens during play
  • Aesthetics – player experience (fun, tension, challenge)

Part 3 – Redesign for a Stakeholder

Choose ONE stakeholder:
  • Competitive Teen eSports Player
  • Busy Working Parent
  • Retired Puzzle Enthusiast
Answer:
  • What changes would improve the game for this player?
  • What mechanics would you add or change?
  • How would the gameplay loop change?
