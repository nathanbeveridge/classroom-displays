Q2 Write Python Code

Use these commands — you used all of them in micro:bit classroom. Combine them to write the program.

The commands you need
micro:bit Python Cheat Sheet
CommandWhat it does
from microbit import * Always first line. Loads all micro:bit tools.
while True: Starts a loop that runs forever. Code inside must be indented.
if ...: Makes a decision. Code inside runs only if the condition is true.
else: Runs when the if condition is false — the "otherwise" option.
button_a.is_pressed() Is Button A being pressed right now? True or False.
display.show(Image.X) Show an image on the LED grid. Replace X with image name.
display.clear() Turn off all LEDs. Blank screen.
Code Structure Hint
Your program needs these parts — in order
1
Import line (the one that loads micro:bit)
2
Start a loop that runs forever
3
Inside the loop: check if Button A is pressed
4
If pressed → show an image
5
Else (not pressed) → clear the screen

Everything inside while True: gets 4 spaces of indent.
Everything inside if and else gets 8 spaces (4 more).

Q5 & Q6 Locker Alarm Pseudocode
Understand the Scenario First
What the locker alarm must do

Light sensor reads a low value (150 or below) → locker is safe → show a tick symbol

Light sensor reads a high value (above 150) → alarm! → show "WARNING" and play a beep

Checks every second and runs forever

Q5 — Your Algorithm MUST Include These 6 Things
Use this as a checklist ✓
  • 1
    Show that the program runs forever — use a forever loop
  • 2
    Read the light sensor value — use SENSE or READ
  • 3
    Use a decision — an IF statement — to compare the value to 150
  • 4
    What happens when the value is above 150? (WARNING + beep)
  • 5
    What happens when the value is 150 or below? (tick symbol)
  • 6
    Add a 1-second delay before checking again — use WAIT
